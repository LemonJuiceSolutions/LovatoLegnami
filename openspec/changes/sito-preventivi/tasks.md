# Tasks

Riferimenti: `specs/*/spec.md` per il comportamento, `design.md` per le decisioni (P1–P13). Prerequisiti: `configuratore-pergole` completata; di `tipologie-estese` servono i task 1–3 (ferramenta in `Assembly.hardware`, metadati `category`/`tags`, mattoni duali con `wallAttachment`) per i gruppi 2–5 e il task 7 (preset) per 4.9, 6.6, 9.x e 11.x; i gruppi 10–12 richiedono anche i task 10–12 di `tipologie-estese` (store, picker, viewer). Ogni task lascia `npm test`, `npm run lint` e `npm run build` verdi; `src/domain/**` resta TypeScript puro; tutti i valori commerciali sono marcati `// DA VALIDARE CON UFFICIO TECNICO/COMMERCIALE`. Nessun servizio esterno è richiesto per sviluppo e test (PGlite, email su console, storage su disco).
